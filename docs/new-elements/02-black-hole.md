# Black Hole

黑洞是第一类明显危险元素，应该晚于基础移动与 combo 理解出现。

## Unlock

- `snakeLength >= 7`

## Spawn Rules

- 低分阶段最多 1 个
- 中后期最多 3 个
- 不在出生点附近生成
- 不在蛇头附近生成
- 不在蛇身上生成
- 不在墙边死角生成
- 不与星核、星门、未来星兽、未来 Boss 重叠
- 生成时走阶段 0 的安全生成函数

## Collision

- 蛇头接触黑洞即死亡
- 命中判定只认真实接触，不做远距离误杀
- 后续黑洞抗性只降低视觉压迫或吸力表现，不改变危险本质

## Visual

- 中心暗核
- 发光吸积盘
- 旋转感
- 轻微脉冲
- 附近粒子只做视觉吸引，不改变蛇的移动轨迹

## Config

- 最大黑洞数量
- 黑洞可见半径
- 黑洞命中半径
- 安全生成距离
- 解锁长度
- 视觉吸力范围
- 脉冲速度
