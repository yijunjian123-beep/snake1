# 局域网固定访问说明

这个项目现在已经把 Vite 开发服务固定为：

- 监听 `0.0.0.0`
- 端口 `5173`
- 端口占用时直接报错，不会自动换到别的端口

所以，`http://10.160.104.97:5173/` 能长期稳定打开，前提是这台机器的局域网 IP 也要固定住。

## 还需要做的事

1. 在路由器里给这台电脑做 DHCP 绑定，或者手动设静态 IP。
2. 保证服务一直在运行，仓库里已经放了启动脚本：`scripts/start-dev-server.ps1`。
3. 如果要开机自动起来，再把这个脚本挂到 Windows 自启动或任务计划里。

## 运行方式

```bash
npm install
npm run dev
```

## 结果

只要 IP 不变、服务不关，局域网里就可以一直用同一个地址访问。
